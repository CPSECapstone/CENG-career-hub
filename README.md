## CENG Career Hub
#### **Sponsored by Cal Poly Engineering Student Council**
The CENG Career Hub is the central location for Cal Poly College of Engineering Students to find career opportunities. This site provides students with personalized recommendations to help them achieve their career goals using Agent Logic and an extensive database of opportunities that are exclusive to Cal Poly students. The Career Hub provides a simple, useful, and trustworthy user experience.
